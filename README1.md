# Step 4 - Integrated Chatbot

## Files

Copy `chatbot.py` into your existing project folder:

medical_chatbot_ml_step1-1/

Your project should contain:

- chatbot.py
- model/intent_classifier.joblib
- model/condition_classifier.joblib

## Run

Open the VS Code terminal in the project folder and run:

python chatbot.py

## Test

Try:

I have fever and cold

I need a hospital

I have severe chest pain

hello

What are some general health tips?

Type:

exit

## Important

This is an educational ML prototype. It does not diagnose disease or prescribe medication.
The next step will add a structured symptom/severity layer and verified Ballari care information.
